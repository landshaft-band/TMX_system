# Wagon WMS/MES

Desktop-приложение на Python + PyQt6 для дипломного проекта: WMS/MES-система склада комплектующих производства железнодорожных вагонов.

## Возможности

- Приёмка комплектующих с вводом штрих-кода и симуляцией умных весов.
- Контроль отклонения веса и регистрация проблемных позиций.
- Реестр заказов и жизненный цикл заказов.
- Управление партиями и жизненным циклом отгрузок.
- Журнал событий.
- История операций по партии.
- Демонстрационная интеграция с 1С.
- Генерация PDF-отчётов.
- Выбор папки сохранения отчётов.
- Роли пользователей и базовые ограничения доступа.
- Сборка в Windows EXE через PyInstaller.

## Запуск из исходников

```powershell
cd C:\Users\winda\Documents\diplom
.\.venv\Scripts\activate
python main.py
```

Если окружение ещё не настроено:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Сборка EXE

```powershell
.\build_exe.ps1
```

Результат:

```text
dist\WagonWMS.exe
```
