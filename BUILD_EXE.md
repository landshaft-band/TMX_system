# Сборка EXE

1. Активируйте виртуальное окружение или используйте проектное `.venv`.
2. Выполните:

```powershell
.\build_exe.ps1
```

После сборки файл будет находиться здесь:

```text
dist\WagonWMS.exe
```

Папка отчётов выбирается в приложении на странице `Отчёты`.
Если папка не выбрана, exe сохраняет отчёты в `reports` рядом с `WagonWMS.exe`.
